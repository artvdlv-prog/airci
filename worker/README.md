# Чат со специалистами — прокси на Cloudflare

Сайт статический (GitHub Pages), поэтому к Claude он обращается через этот небольшой сервер.
Ключ API хранится только здесь, в секретах Cloudflare, и в браузер не попадает.
Роли специалистов задаются в `src/specialists.js` — посетитель не может подменить их.

## Что нужно

- API-ключ Anthropic: https://console.anthropic.com → API Keys.
  Там же задайте месячный лимит расходов (Settings → Limits): чат открыт всем.
- Бесплатный аккаунт Cloudflare: https://dash.cloudflare.com/sign-up
- Node.js 20+ на компьютере, с которого разворачиваете.

## Запуск

```bash
cd worker
npm install
npx wrangler login                          # вход в Cloudflare через браузер
npx wrangler secret put ANTHROPIC_API_KEY   # вставьте ключ, когда спросит
npx wrangler deploy
```

После `deploy` wrangler покажет адрес вида `https://airchitect-chat.<аккаунт>.workers.dev`.
Впишите его в `home-config.js` в корне сайта, добавив `/chat`:

```js
const HOME_ASSISTANT_API = 'https://airchitect-chat.<аккаунт>.workers.dev/chat';
```

Опубликуйте сайт — во вкладке «Чат» раздела «Штат» (`staff.html?id=…`) заработает чат со специалистом.

## Настройки

- `wrangler.toml` → `ALLOWED_ORIGINS` — сайты, которым разрешено обращаться к чату.
  Для проверки с компьютера добавьте, например, `http://localhost:8000`.
- `wrangler.toml` → `[[ratelimits]]` — не больше 20 сообщений в минуту с одного IP.
- `src/index.js` → `MODEL`, `MAX_TOKENS`, лимиты на размер и число файлов.
- Новый специалист: добавьте его в `home-config.js` (страница и карточка на сайте)
  **и** в `src/specialists.js` с тем же `slug` (роль для чата), затем `npx wrangler deploy`.

## Что умеет

- Отвечает потоком, текст появляется по мере генерации.
- Принимает PDF, изображения (PNG, JPEG, WEBP, GIF) и текстовые файлы — до 3 файлов по 10 МБ к сообщению.
- При отказе модели по соображениям безопасности запрос автоматически продолжается
  на рекомендованной Anthropic запасной модели (`fallbacks: "default"`).
- Повторно используемая часть диалога (роль, ранние сообщения, документы) берётся из кэша — это дешевле.

## Извлечение обязательств из договора

Раздел «Контракты» (`contracts.html`) отправляет файл договора на `POST /extract` того же адреса.
Прокси возвращает реквизиты и обязательства сторон в виде JSON (строгая схема ответа).
Извлечённые обязательства попадают в реестр со статусом «Требует подтверждения» — их нужно проверить вручную.

## Анализ закупок по ссылкам

Тендерный специалист (`tender-specialist`) находит ссылки в сообщении; пользователь отмечает, какие анализировать,
и выбирает «Справка по каждой» или «Сводное сравнение». Чат передаёт их в поле `analysis` запроса `/chat`:
`{ "type": "tenders", "urls": [...], "mode": "each" | "compare" }` (до 6 ссылок).

Прокси подключает серверный инструмент `web_fetch`: страницы открывает API Anthropic, а не браузер,
и данные берутся только из полученных страниц и приложенных файлов. Если страница недоступна
(например, площадка блокирует автоматические запросы или документация в архиве), специалист
сообщает об этом и просит загрузить документацию. Во время загрузки чат показывает статус
«Открываю страницу закупки…». Длинные анализы продолжаются автоматически (до 4 продолжений `pause_turn`).

В конце ответа модель добавляет служебный блок ` ```airchitect-data ``` ` с полями закупок (JSON). Чат его не показывает,
а кнопка «Сохранить в реестр тендеров» переносит сведения в `tenders.html`. Заполняются только пустые поля,
введённые вручную сведения не перезаписываются.

## Ограничения

- История диалога хранится только в открытой вкладке браузера; после перезагрузки страницы она теряется.
- Документы из диалога отправляются заново с каждым сообщением (API не хранит состояние) —
  длинные диалоги с большими PDF дороже. Кнопка «Новый диалог» начинает заново.
