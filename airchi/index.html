Задача

Цель применения ИИ — сократить время на работу с текстами и данными при сохранении качества решений. ИИ готовит черновик анализа: находит условия, сопоставляет документы, предлагает формулировки. Специалист проверяет ключевые выводы по первоисточнику и принимает решение.

Порядок работы

  1. Постановка задачи
  2. Передача документов
  3. Анализ
  4. Проверка по источникам
  5. Решение специалиста
  6. Сохранение результата
  1. Сформулировать задачу и ожидаемый результат: что нужно получить — перечень, таблицу, заключение, проект письма — и для какого решения.
  2. Передать полный документ, а не фрагмент: вывод по части договора может противоречить другим его разделам.
  3. Требовать ссылки на пункт, страницу или документ для каждого существенного вывода.
  4. Проверить ключевые выводы по первоисточнику: суммы, даты, сроки, номера норм.
  5. Принять решение — это делает специалист, а не модель.
  6. Сохранить результат вместе с исходными документами, чтобы к нему можно было вернуться.

Ограничения

  • Ошибки и «додумывание». Модель может уверенно привести несуществующий пункт или неверную дату. Поэтому существенные выводы проверяются по источнику.
  • Дата знаний. Знания модели ограничены датой обучения; изменения законодательства после неё модель может не знать. Нормы проверяются по официальным публикациям или через поиск на сервере.
  • Только переданные данные. Модель не видит того, что ей не передали: письма, устные договорённости, фактическое состояние объекта.
  • Качество исходников. Плохо отсканированные документы распознаются с ошибками — особенно таблицы и числа.
  • Ответственность. ИИ не является стороной договора и не несёт ответственности за решение; её несут компания и её специалисты.

Документы

  • Политика применения ИИ: для каких задач, какие данные можно передавать, кто проверяет результат.
  • Перечень сведений, составляющих коммерческую тайну, и режим их защиты (98-ФЗ).
  • Документы по обработке персональных данных, если они передаются сервису (152-ФЗ).
  • Договор или условия использования сервиса: где обрабатываются данные, хранятся ли они, используются ли для обучения.

Результат

  • Время на первичный анализ документов сокращается, специалист сосредоточен на решениях.
  • Каждый существенный вывод подтверждён ссылкой на источник.
  • Компания понимает, какие данные и каким сервисам она передаёт.

Пример: обязательства из договора подряда

Условный пример

Договор подряда на 40 страниц с приложениями нужно разобрать на обязательства для реестра.

  1. ИИ получает договор целиком и задачу: перечень обязательств обеих сторон со сроками, ответственным и пунктом договора.
  2. Результат — таблица; по каждой строке есть ссылка на пункт.
  3. Договорной специалист сверяет даты и формулировки с текстом и добавляет обязательства из приложений, которые были переданы отдельным файлом.
  4. Проверенный перечень вносится в реестр обязательств.

Работа, которая вручную занимает несколько часов, сводится к проверке готовой таблицы. Ответственность за перечень остаётся у специалиста.

Нормативные основания

Номер документа — ссылка на официальную публикацию, если она есть в реестре AIRCHITECT. Перед применением проверяйте действующую редакцию.

Частые вопросы

Может ли ИИ заменить юриста или инженера-сметчика?

Нет. ИИ ускоряет подготовку анализа, но квалификация, проверка и решение остаются за специалистом, который несёт за них ответственность.

Можно ли передавать ИИ договоры с персональными данными?

Только при соблюдении 152-ФЗ: должно быть правовое основание обработки, а условия сервиса — понятны. Если персональные данные для задачи не нужны, их лучше удалить или обезличить.

Как проверить ответ ИИ?

Открыть указанный пункт документа и сверить текст, пересчитать ключевые числа, проверить номер и редакцию нормы в официальном источнике. Ответ без ссылок на источник использовать для решений не следует.

Знает ли ИИ актуальные нормы?

Не всегда: знания модели ограничены датой её обучения. Актуальность проверяется по официальным публикациям — вручную или с помощью поиска на сервере с указанием источника.
